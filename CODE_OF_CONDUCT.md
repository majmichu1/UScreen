# Code of Conduct

Be decent. Concretely:

- Treat everyone in issues, discussions and reviews with respect. Disagree
  with ideas, not people.
- No harassment, discrimination, or personal attacks of any kind.
- Assume good faith. A report that turns out to be user error is still useful.
- Keep it on topic and keep it constructive.

Maintainers may edit or remove content and block accounts that ignore this.
Report problems privately through the maintainer's GitHub profile.
